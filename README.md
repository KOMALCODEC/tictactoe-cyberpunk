# 🎮 Tic Tac Toe — Cyberpunk Edition

A stunning **2-player local multiplayer** Tic Tac Toe game built with pure HTML, CSS, and JavaScript — featuring a dark cyberpunk aesthetic with neon glow effects, sound effects, and smooth animations.

## ✨ Features

- 🎮 **2-Player Local Multiplayer** — Play with a friend on the same device
- 🌟 **Cyberpunk Neon Theme** — Dark mode with glowing X and O
- 🔊 **Sound Effects** — Unique tones for X moves, O moves, wins & draws (Web Audio API)
- 🏆 **Score Tracker** — Persistent score across rounds
- ✍️ **Player Name Customization** — Enter your own names before starting
- ⚡ **Win Line Animation** — Neon line drawn through the winning combo
- 🎉 **Particle Effects** — Explosion of particles on win
- ⌨️ **Keyboard Controls** — Play with numpad (1-9), R to reset, N for new game
- 📱 **Responsive** — Works on desktop and mobile

## 🚀 How to Play

1. Open `index.html` in your browser
2. Enter player names (optional)
3. Click **START GAME**
4. Players take turns clicking cells
5. First to get 3 in a row wins!

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `1`-`9` | Play a cell (numpad layout) |
| `R` | Reset the round |
| `N` | Start a new game |
| `Enter` | Start the game (on setup screen) |

## 📦 Run Locally

No build step needed! Just open `index.html` directly in any modern browser.

```bash

git clone https://github.com/YOUR_USERNAME/tictactoe-cyberpunk.git

# Open in browser
open index.html   # Mac
start index.html  # Windows
```
